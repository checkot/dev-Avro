# Sum Keyboard — User Guide

Maintained by **Md. Ariful Islam** ([`checkot/dev-Avro`](https://github.com/checkot/dev-Avro)).

## 1. Setup & Everyday Typing
1. Install the latest `MyAvroKeyboard-debug.apk` from [`checkot/dev-Avro/releases`](https://github.com/checkot/dev-Avro/releases).
2. Open **Sum Keyboard** → tap **Enable Sum Keyboard** → turn it ON → tap **Switch keyboard** and select **Sum Keyboard**.
3. **Switch languages:** Hold and slide the **Spacebar** left or right to switch between **English**, **Avro**, **Probhat**, and **জাতীয়**.
4. **Toolbar toggles:** Tap **Numpad**, **Clipboard**, or **Emoji** once to open, and tap the same icon again to close.
5. **Quick symbols:** Long-press any letter key for its corner symbol (`৳`, `%`, `_`, `;`, `@`, `#`, `&`, `/`, etc.). Adjust long-press speed (`150ms–600ms`) in **Settings → Preferences**.

## 2. Top-Bar PC Developer Keyboard (`</>` → `PC` → `Fn`)
- **1st tap (`</>` → `PC`):** Opens the full PC coding layout (`Esc`, `Tab`, `Shift`, `Alt`, `⌘`, `Ctrl`, number/symbol row).
- **2nd tap (`PC` → `Fn`):** Opens Function keys (`F1–F12`), arrow keys (`↑ ↓ ← →`), `Home`, `End`, `PgUp`, `PgDn`, `Ins`, `Del`, and `Cut`/`Copy`/`Paste`.
- **3rd tap (`Fn` → `</>`):** Returns to your normal typing keyboard.
- Looking for the Avro phonetic chart? Open **Sum Keyboard → Developer Mode → Avro Typing Guide (Keymap)**.

## 3. Gemini AI Live Voice Typing
1. Open **Sum Keyboard → Developer Mode → AI Voice Typing (Gemini)**.
2. Tap **Grant Microphone Permission** → **Allow**.
3. Paste your free [Google AI Studio](https://aistudio.google.com/apikey) API key (stored locally on your phone only).
4. Keep **Gemini Model ID** set to `gemini-3.5-flash-lite`, choose **Auto (BN+EN)** / **বাংলা** / **English**, and tap **Save & Test Gemini Connection**.
5. Tap the **Microphone icon** in the top-right corner of the keyboard:
   - **Red + dot:** Live listening ON — pause ~1 second after a sentence to auto-type while keeping the mic open.
   - **Tap again:** Stops listening.

## 4. Pro Cursor Controls
- **Spacebar Hold Cursor:** Press and hold Spacebar (~0.8s) until `◀ Cursor ▶` appears, then slide left/right to move the cursor precisely.
- **Volume Button Cursor:** Enable in **Settings → Cursor control** to move the cursor with Volume Up/Down while typing (automatically disabled during media playback).

## 5. Custom Hardware Shortcuts & Text Macros
1. Open **Sum Keyboard → Developer Mode → Hardware Shortcuts & Macros**.
2. Turn **Enable Developer Mode** ON (default is OFF).
3. Tap **+ Add Shortcut**, capture a physical key combo (or choose modifiers + key manually), enter a name and Bangla/English multiline macro, and save.

## 6. In-App Updates
- Open **Sum Keyboard** → tap **Check for updates** (or the top **Update available** banner) to download and install new releases from [`checkot/dev-Avro`](https://github.com/checkot/dev-Avro/releases) directly inside the app.
